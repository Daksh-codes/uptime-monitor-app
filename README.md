# Uptime Monitor (WIP 🚧)

A simple uptime monitoring service that tracks the availability of websites and APIs.

## 🚀 Status

This project is currently in progress. Core features are being built.

## ✨ Planned Features

* Add and manage monitored URLs
* Basic uptime tracking (status checks)
* Response time logging
* Dashboard to view uptime history
* Alerts (future)

## 🛠 Tech Stack
* Frontend: React
* Backend: Node.js + Express + Typescript
* Database: PostgreSQL (Neon)
* ORM: Prisma

## ⚙️ Current Progress

* Project setup complete
* Database schema in progress
* Basic monitoring logic being implemented

## 📌 Notes

* This is an early version focused on learning and iteration
* Features and structure may change

## 🧠 Goal

Build a lightweight uptime monitoring tool with clean architecture and scalable design.
